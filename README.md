Classroom Noise Detector

Description:
This is a classroom noise detector built using arduino, mic, 16x2 I2C LCD display, an SD card module and a button. The wiring, instructions, and more is given in the .ino, which is the file format for arduino code. The streamlit website, clsnoise.streamlit.app is deployed and you can upload .log files recorded in sd card to the website to see graphs, select periods (in my school) and see average noise level in each session. 

Version 1.0
